# API

Interactive docs are auto-generated by FastAPI once the backend is running:

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc
- OpenAPI JSON: http://localhost:8000/openapi.json

This page is a quick reference; the interactive docs are the authoritative,
always-in-sync source (they're generated directly from the Pydantic schemas).

## Auth

All endpoints except `/api/auth/register`, `/api/auth/login`,
`/api/auth/refresh`, and `GET /api/recycling-centers*` require a
`Authorization: Bearer <access_token>` header. Get a token pair from
`/api/auth/login` or `/api/auth/register`.

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/register` | Create an account, returns token pair |
| POST | `/api/auth/login` | Returns token pair |
| POST | `/api/auth/refresh` | Exchange refresh token for a new access token |
| GET | `/api/auth/me` | Current user |
| POST | `/api/auth/logout` | Stateless logout (client discards tokens) |

## Waste reports & ML

| Method | Path | Role |
|---|---|---|
| POST | `/api/waste/report` | USER — multipart: image, latitude, longitude, description?, address?, manual_category? |
| GET | `/api/waste/reports` | USER — own reports |
| GET | `/api/waste/reports/{id}` | owner or ADMIN |
| PATCH | `/api/waste/reports/{id}/status` | ADMIN |
| POST | `/api/ml/classify` | any authenticated user — standalone preview, doesn't persist |
| GET | `/api/ml/status` | current ML_MODE |

Example `POST /api/waste/report` response:
```json
{
  "id": 1,
  "category": "Plastic",
  "status": "PENDING",
  "ml_prediction": {
    "category": "Plastic",
    "confidence": 0.94,
    "recyclable": true,
    "recommended_disposal": "Recycling Center",
    "mode": "demo"
  }
}
```

## WebSocket

`ws://localhost:8000/ws/notifications?token=<access_token>` — pushes a JSON
message (`{"type": "notification", "title": ..., "message": ...}`) whenever a
pickup status changes or a notification is created for the connected user.
